# Mad Compass content handoff

Edit these files when client content arrives:

- data/content.ts — brand info, address, contact details, social links, hero copy
- data/packages.ts — all package entries, pricing, highlights, featured flags
- data/testimonials.ts — testimonial quotes and trip context
- app/globals.css or tailwind config — brand colors and design tokens

Keep component structure intact and swap values in the data files first.
